Integración de ramas

-git merge
git merge sirve para unir los cambios de una rama con otra. Se usa cuando terminamos una tarea en una rama y queremos agregar esos cambios a otra rama. Por ejemplo "git merge rama-destino"

-git rebase
git rebase también permite integrar cambios entre ramas, pero reorganiza los commits para que el historial quede más ordenado. Por ejemplo "git rebase main"

-Diferencia entre merge y rebase
merge une ramas manteniendo el historial original.
rebase reorganiza los commits para que el historial quede más limpio.
